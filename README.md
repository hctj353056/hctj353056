## 关于我

我持续探索哲学、认知与人工智能。

比起收集结论，我更关心结论如何形成、依据是什么，以及它能否经受检验与修正。

我希望理解的不只是世界如何运行，也包括：

- 认知如何逼近真实？
- 不同学科之间是否存在更深层的范畴结构？
- 主体如何形成、维持并修正自身的认知结构？
- 理解如何转化为行动，并反过来改变世界？

## 思考与实践

我的探索通常从问题出发，经由概念构造、逻辑推演与实践验证，逐步修正。

我重视：

- 真实与可验证性
- 理解而非背诵
- 逻辑一致与持续修正
- 自主判断与主体责任
- 求同存异、独立发展

这些是我的工作取向，不意味着我已经解决了上述问题。
